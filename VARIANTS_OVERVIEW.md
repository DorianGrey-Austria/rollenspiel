## 🔧 Technical Specs

### All Variants Share:
- React 19 + TypeScript 5.9
- Tailwind CSS 4.x
- DaisyUI 5.x
- Zustand for state management
- React Router 7.x
- Anthropic Claude AI API
- Vite 7.x build tool

### Color Philosophy:
- **v1 Variants**: Mix of custom and Tailwind colors
- **v2 Variants**: Only Tailwind standard colors (better stability)

### Feature Levels:
1. **Minimal** (E, F): Age selection, location input, story display
2. **Enhanced** (E2, F2): + Timeline, simple achievements, stats
3. **Full** (D, D2): + Complex achievements, XP system, persistence
